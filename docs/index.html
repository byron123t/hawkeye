Abstract

While modern Vision-Language Models (VLMs) have been remarkably successful in general scene text recognition, they consistently struggle with the long-tail distribution of text that is degraded by motion blur or low resolution. These limitations are particularly apparent in egocentric applications like smart glasses, where text is often captured in noisy environments. In this paper, we introduce the BSTRB (Blurry Scene Text Recognition Benchmark), a novel benchmark of 9,936 noisy image samples with high-fidelity ground-truth annotations derived from 1,699 real-world video sequences. To support this, we present Hawkeye4B, a VLM fine-tuned on BSTRB to read and reason about illegible text by leveraging deep contextual priors and pixel-level visual alignment. Our results show that Hawkeye4B matches or exceeds text transcription performance on much larger closed-weight VLMs, making it practical for real-time deployment. We characterize the text resolution at which current VLMs begin to fail.

Method

  • Base models. Hawkeye 4B and Hawkeye 8B start from Qwen3-VL-4B-Instruct and Qwen3-VL-8B-Instruct.
  • Training. Supervised fine-tuning on BSTRB video frames, then GRPO reinforcement learning with a bag-of-words F1 reward against the transcription.
  • Inference. The input is upscaled ×3 with bicubic interpolation (no learned super-resolution) and capped at about 1 MP; one greedy pass, no visual chain-of-thought, no tools.

The BSTRB benchmark

BSTRB pairs real, degraded captures with transcriptions made while the text was still legible. Participants filmed everyday objects (packaging, books, screens, signs, medicine, documents) at home, walking backwards so the text shrinks frame by frame; six frames are sampled per video, and the video's transcription is the target for every frame. The evaluation splits use human-verified (“golden”) transcriptions.

Where Hawkeye looks

We record each generated token's attention to the image (last four layers, attention-sink patches excluded). Both base and Hawkeye attend to the word they are writing far above chance, and Hawkeye does not visit more text regions on average. What changes is how far it reads: on small text it goes on into fine print the base skips, and it stops less often after a title or falls into a loop. Quick start

The hawkeye package applies the exact protocol used in the paper: an OCR system prompt, the image upscaled ×3 with bicubic interpolation (the processor then caps it at 1,003,520 pixels), greedy decoding. A plain transformers version is on the model card; training, evaluation and analysis code is in the GitHub repository.

pip install "hawkeye[infer] @ git+https://github.com/byron123t/hawkeye"

from hawkeye import Hawkeye
reader = Hawkeye("byron123t/Hawkeye-4B")      # or "byron123t/Hawkeye-8B"
print(reader.read("frame.jpg"))

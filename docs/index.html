From legible to illegible in a few steps

Every BSTRB clip is filmed walking backwards from an object, so one human-checked transcription covers frames whose text shrinks from about 20 px to under 5 px tall. That is the range where reading breaks down.

Fast enough to read live

Hawkeye reads a frame in about a second on one local GPU, as fast as the much larger Qwen3-VL-235B behind an API and 9–13× faster than the reasoning API models, with no per-image cost. All models read the same crops from the demo clips.

The BSTRB benchmark

People filmed everyday objects at home (packaging, books, medicine, signs, screens) while stepping back. Six frames per clip and one transcription per clip, checked by hand for the evaluation splits.

Dataset details

No video appears in more than one split. Validation was used to choose the training recipe and checkpoints; results are on the held-out test split. File names are neutral ids, image metadata (including GPS) was removed, and the data is gated behind a data-use agreement. Automatic training labels for photos are often incomplete, which is why Hawkeye trains on video frames only.

Where Hawkeye looks

Attention maps show the difference: the base model stays on the big print, while Hawkeye also looks at the small print, and then writes it down.

How this was measured

Attention to image patches from the last four layers, averaged over heads, with content-free "attention sink" patches excluded. Across all frames, both models' attention lands on the word being written far above chance, and Hawkeye does not visit more text regions on average; what changes is how far it keeps reading. How it works

  1. Start from an open model. Hawkeye 4B and 8B begin as Qwen3-VL-4B and -8B.
  2. Show it real blur. Fine-tune on BSTRB video frames, then reward it for every correct word it reads.
  3. Read in one pass. Enlarge the image 3× and read once: no chain-of-thought, no tools, no second look.
Technical details
  • Training. Supervised fine-tuning on 6,734 BSTRB training frames (vision encoder unfrozen, 420 steps), then GRPO with LoRA (rank 64) and a bag-of-words F1 reward against the transcription, 300 steps.
  • Inference. An OCR system prompt, the instruction, then the image upscaled ×3 with bicubic interpolation (the processor caps it at about 1 MP); greedy decoding, up to 4,096 new tokens.
  • Evaluation. Every model gets the same prompt and image; scores are per image after normalizing case, punctuation and whitespace.

Abstract

While modern Vision-Language Models (VLMs) have been remarkably successful in general scene text recognition, they consistently struggle with the long-tail distribution of text that is degraded by motion blur or low resolution. These limitations are particularly apparent in egocentric applications like smart glasses, where text is often captured in noisy environments. In this paper, we introduce the BSTRB (Blurry Scene Text Recognition Benchmark), a novel benchmark of 9,936 noisy image samples with high-fidelity ground-truth annotations derived from 1,699 real-world video sequences. To support this, we present Hawkeye4B, a VLM fine-tuned on BSTRB to read and reason about illegible text by leveraging deep contextual priors and pixel-level visual alignment. Our results show that Hawkeye4B matches or exceeds text transcription performance on much larger closed-weight VLMs, making it practical for real-time deployment. We characterize the text resolution at which current VLMs begin to fail.

Try it

A few lines with the hawkeye package, which applies the exact setup used in the paper.

# pip install "hawkeye[infer] @ git+https://github.com/byron123t/hawkeye"
from hawkeye import Hawkeye

reader = Hawkeye("byron123t/Hawkeye-4B")      # or "byron123t/Hawkeye-8B"
print(reader.read("photo.jpg"))

A plain transformers version is on the model card; training, evaluation and analysis code is in the GitHub repository.
